# Remote Gallery Database Schema (Phase 1)

This document provides details on the database tables, indexes, constraints, and Row Level Security (RLS) policies implemented for Phase 1 of the Remote Gallery System.

---

## 1. Tables

### A. `public.profiles` (Modified)
We added the administrative status flag:
* `is_admin` (`boolean`, `NOT NULL`, default `false`): Controls dashboard access.

### B. `public.devices`
Represents client installations registered on active Calendar apps:
* `id` (`uuid`, `PRIMARY KEY`, default `gen_random_uuid()`): Unique database record ID.
* `user_id` (`uuid`, references `profiles(id)` on delete cascade): Owner account.
* `device_id` (`text`, `UNIQUE`, `NOT NULL`): Client-persisted unique hardware ID wrapper.
* `device_name` (`text`, `NOT NULL`): Readable device label.
* `device_model` (`text`, `NOT NULL`): Native device hardware model.
* `platform` (`text`, `NOT NULL`): OS platform (e.g. `'android'`, `'web'`).
* `os_version` (`text`, `NOT NULL`): Operating system version.
* `app_version` (`text`, `NOT NULL`): Current app compilation version.
* `is_online` (`boolean`, `NOT NULL`, default `false`): Offline/Online state.
* `last_seen` (`timestamp with time zone`, default `now()`): Last heartbeat sync time.
* `is_paired` (`boolean`, `NOT NULL`, default `false`): pairing status.
* `paired_at` (`timestamp with time zone`): Date when the pairing transaction finished.
* `created_at` (`timestamp with time zone`, default `now()`): Creation date.
* `updated_at` (`timestamp with time zone`, default `now()`): Last modification date.

### C. `public.pairing_codes`
Tracks activation sessions generated by administrators:
* `id` (`uuid`, `PRIMARY KEY`, default `gen_random_uuid()`): Unique transaction identifier.
* `code_hash` (`text`, `UNIQUE`, `NOT NULL`): SHA-256 hash of the generated code (e.g. `A7K9-29MX`).
* `created_by` (`uuid`, references `profiles(id)` on delete cascade): Generating administrator.
* `expires_at` (`timestamp with time zone`, `NOT NULL`): Expiration timestamp (15 minutes).
* `used_at` (`timestamp with time zone`): Verification timestamp if redeemed.
* `device_id` (`uuid`, references `devices(id)` on delete set null): Linked device UUID.
* `created_at` (`timestamp with time zone`, default `now()`): Code generation timestamp.

### D. `public.audit_logs`
Logs sensitive administrative operations for audit logs:
* `id` (`uuid`, `PRIMARY KEY`, default `gen_random_uuid()`): Log event ID.
* `admin_user_id` (`uuid`, references `profiles(id)` on delete set null): Operating administrator.
* `action` (`text`, `NOT NULL`): Action tag (e.g. `DEVICE_PAIR`, `DEVICE_UNPAIR`, `DEVICE_PAIR_GENERATE`).
* `target_user_id` (`uuid`, references `profiles(id)` on delete set null): Targeted user account.
* `target_device_id` (`uuid`, references `devices(id)` on delete set null): Targeted device record.
* `metadata` (`jsonb`, default `'{}'`): Dynamic parameters or metadata.
* `created_at` (`timestamp with time zone`, default `now()`): Log timestamp.

---

## 2. Performance Indexes

To optimize queries on registered lists and real-time polling updates, the following indexes are defined:
* `idx_devices_user_id` on `devices(user_id)`
* `idx_devices_is_online` on `devices(is_online)`
* `idx_devices_last_seen` on `devices(last_seen)`
* `idx_pairing_codes_code_hash` on `pairing_codes(code_hash)`
* `idx_audit_logs_created_at` on `audit_logs(created_at)`

---

## 3. RLS Policies

Row Level Security is enabled on all tables:

```sql
-- 1. Helper checks
CREATE OR REPLACE FUNCTION public.is_admin()
RETURNS BOOLEAN AS $$
  SELECT COALESCE(
    (SELECT is_admin FROM public.profiles WHERE id = auth.uid()),
    false
  );
$$ LANGUAGE sql SECURITY DEFINER;

-- 2. Devices Table
-- Users can view their own devices
CREATE POLICY "Users can read own devices" ON public.devices FOR SELECT USING (user_id = auth.uid());
-- Users can insert and update their own devices
CREATE POLICY "Users can insert own devices" ON public.devices FOR INSERT WITH CHECK (user_id = auth.uid());
CREATE POLICY "Users can update own devices" ON public.devices FOR UPDATE USING (user_id = auth.uid());
-- Admins can view and update all devices
CREATE POLICY "Admins can select all devices" ON public.devices FOR SELECT USING (public.is_admin());
CREATE POLICY "Admins can update all devices" ON public.devices FOR UPDATE USING (public.is_admin());

-- 3. Pairing Codes Table
-- Admins have full access
CREATE POLICY "Admins have full access to pairing codes" ON public.pairing_codes FOR ALL USING (public.is_admin());

-- 4. Audit Logs Table
-- Admins can select logs
CREATE POLICY "Admins can select audit logs" ON public.audit_logs FOR SELECT USING (public.is_admin());
```
